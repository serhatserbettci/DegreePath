# DegreePath

## Project Description
DegreePath is a web-based academic planning and graduation decision support system designed for Software Engineering students at Altınbaş University. The application aims to help students track their academic progress, understand course prerequisites, and plan future semesters.

## Objective
The main objective of this project is to provide students with a tool that makes academic planning easier and helps them understand how their course decisions may affect their progress toward graduation.

## Target Users
The initial version of DegreePath is intended for students enrolled in the English Software Engineering program at Altınbaş University.

## Planned Technologies
The following technologies are being considered for development:

- **Frontend:** React
- **Backend:** Python and FastAPI
- **Database:** SQLite
- **Course Dependency Analysis:** NetworkX
- **Version Control:** Git and GitHub

These technologies may change during the development process.

## Current Status
Week 1 - Project definition and initial research.

The project is currently in its planning stage. The initial requirements and scope have been defined, and preliminary academic and technical research has begun.

## Planned Features

### 1. Academic Progress Tracker
Students will be able to enter their completed, failed, and deferred courses. The system will display their academic progress and remaining graduation requirements.

### 2. Semester Planner
The application will analyze course prerequisites and suggest courses that students may be eligible to take in upcoming semesters.

### 3. What-If Simulator
Students will be able to simulate hypothetical situations, such as failing or postponing a course, and see how these decisions might affect their future academic plans.

## Initial Project Scope

The first version will focus on the English Software Engineering program at Altınbaş University.

The following features will not be included in the initial version:

- Direct integration with the university's student information system
- Automatic course registration
- Real-time class schedule tracking
- AI-based academic advising

Course information will be based on publicly available university curriculum information.
